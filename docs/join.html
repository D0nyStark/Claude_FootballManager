⚽ 풋살 팀메이커

실력 균형이 맞는 풋살 팀을 자동으로 짜 주는 앱이에요.

앱에서 열기 웹앱으로 열기 다른 브라우저로 열기

아이폰은 웹앱으로 써요

  1. [웹앱으로 열기]를 누르면 사파리에서 바로 모임에 참여해요.
  2. 사파리 공유 버튼 → 홈 화면에 추가로 설치해 두면 앱처럼 쓸 수 있어요.
  3. 홈 화면 앱은 사파리와 저장 공간이 따로예요. 설치한 앱에서 [초대 링크로 참여]에 이 링크를 붙여넣어 주세요 ([링크 복사]).
  4. 폰을 가로로 돌려서 써요.

처음 설치하는 경우 (안드로이드)

  1. [앱 설치]를 누르면 초대 링크가 자동으로 복사돼요.
  2. 설치한 앱을 열면 복사된 초대를 알아보고 참여할지 물어봐요.
  3. 안 되면 카카오톡의 초대 링크를 한 번 더 눌러 주세요.

초대 정보가 없는 링크예요. 카카오톡으로 받은 링크 전체를 다시 눌러 주세요.

모임 데이터는 링크의 '#' 뒤에만 있고 이 페이지의 서버로 전송되지 않아요.
